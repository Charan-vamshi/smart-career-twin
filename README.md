## 📖 Overview

**Smart Career Twin** is a full-stack web application that helps engineering students understand their placement readiness. It analyzes your academic profile, skills, projects, and coding stats to:

- **Predict** your probability of landing a Tier 1, Tier 2, or Tier 3 company placement
- **Generate** a personalized, AI-powered career roadmap using Google Gemini

Think of it as your digital career twin — it knows your strengths, identifies your gaps, and tells you exactly what to do next.

## 🚀 How to Use

> The app is fully live — no setup needed. Just visit **[smart-career-twin.vercel.app](https://smart-career-twin.vercel.app)**

### Step-by-step:

**1. Sign in with Google**
Click **"Continue with Google"** on the landing page. You'll be asked to pick your Google account (account picker is always shown — no silent auto-login).

**2. Complete your Profile (Onboarding Wizard)**
A 4-step wizard collects your profile:

- **Step 1 — Academic:** Enter your CGPA (out of 10) and whether it's improving, stable, or declining.
- **Step 2 — Skills:** Search and select your skills (Java, Python, ML, DSA, etc.) from a curated list. Set your proficiency level for each.
- **Step 3 — Projects:** Add projects you've built. Choose category, complexity, deployment status, tech stack (searchable), and describe your role and outcome.
- **Step 4 — Stats:** Enter your competitive coding stats (total problems solved on LeetCode/GFG etc.) and GitHub activity (repos, active months, stars).

Click **"Finish & View Dashboard"** when done.

**3. View Your Placement Prediction**
The dashboard shows your predicted probability (%) for:
- 🏆 **Tier 1** — Top product-based companies (Google, Microsoft, etc.)
- 🥈 **Tier 2** — Mid-level product & service companies
- 🥉 **Tier 3** — Entry-level / service-based companies

**4. Generate Your AI Roadmap**
Click **"Generate AI Roadmap"**. Google Gemini analyzes your full profile and generates a personalized, phase-by-phase plan with specific action items to improve your placement chances. You can download it as a Markdown file.

**5. Edit Profile Anytime**
Click **"Edit Profile"** on the dashboard to return to the onboarding wizard. Your existing data is pre-filled — you can add, update, or remove skills and projects.

> ⚠️ **Cold Start Note:** The backend runs on Render's free tier. If it hasn't been used recently, the first request may take up to 50 seconds to wake up. The app will show a warning message if this happens — just wait, it'll come through.

## 💻 Local Development

### Prerequisites
- Java 17+
- Node.js 18+
- Maven
- MySQL instance (or use Aiven free tier)

### Backend Setup

1. **Clone the repo**
   ```bash
   git clone https://github.com/Charan-vamshi/smart-career-twin.git
   cd smart-career-twin
   ```

2. **Create a `.env` file** in the project root:
   ```env
   MYSQL_URL=jdbc:mysql://your-host:port/dbname
   MYSQL_USER=your_db_user
   MYSQL_PASSWORD=your_db_password
   GOOGLE_CLIENT_ID=your_google_client_id
   GOOGLE_CLIENT_SECRET=your_google_client_secret
   JWT_SECRET=your_jwt_secret_min_32_chars
   GEMINI_API_KEY=your_gemini_api_key
   GEMINI_API_URL=https://generativelanguage.googleapis.com/v1beta/models/gemini-pro:generateContent
   FRONTEND_URL=http://localhost:3000
   ```

3. **Run the backend**
   ```bash
   ./mvnw spring-boot:run
   ```
   Backend starts at `http://localhost:8080`

### Frontend Setup

1. **Navigate to frontend**
   ```bash
   cd frontend
   ```

2. **Create `.env`**
   ```env
   VITE_API_BASE_URL=http://localhost:8080
   ```

3. **Install and run**
   ```bash
   npm install
   npm run dev
   ```
   Frontend starts at `http://localhost:3000`

> ⚠️ The frontend **must** run on port 3000 (configured in `vite.config.ts`) because that's the OAuth2 redirect URL the backend is configured for in local dev.

### Backend (Render / `.env`)

| Variable | Description |
|---|---|

## 📡 API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/profile` | Get full user profile |
| `PUT` | `/api/profile/academic` | Update CGPA and trend |
| `POST` | `/api/profile/skills` | Add a skill |
| `DELETE` | `/api/profile/skills/{id}` | Remove a skill |
| `POST` | `/api/profile/projects` | Add a project |
| `DELETE` | `/api/profile/projects/{id}` | Remove a project |
| `PUT` | `/api/profile/coding-stats` | Update coding platform stats |
| `PUT` | `/api/profile/github-stats` | Update GitHub stats |
| `GET` | `/api/predict` | Get placement tier predictions |
| `POST` | `/api/roadmap` | Generate AI career roadmap |

All `/api/**` endpoints require a `Bearer <jwt>` token in the `Authorization` header.
